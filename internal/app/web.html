Exportação de dados do titular (Art. 18 LGPD)

Gera um arquivo JSON com todos os dados pessoais do cliente, incluindo pedidos, consentimentos e pagamentos.

Exclusão/Anonimização de dados (Art. 18 LGPD)

Atenção: Se o cliente tiver pedidos não cancelados, os dados serão anonimizados (mantidos para conformidade fiscal) em vez de excluídos. A anonimização remove dados pessoais (nome, telefone, e-mail, documento) mas preserva os registros de pedidos para fins contábeis.

Políticas de retenção

  • Dados de pedidos: Mantidos por 5 anos após o último pedido (conformidade fiscal)
  • Consentimentos: Mantidos enquanto válidos + 5 anos após revogação
  • Logs de auditoria: Mantidos por 2 anos
  • Backups: Seguem a mesma política dos dados originais

Saúde e manutenção

Integrações desabilitadas. WhatsApp oficial e gateways exigem credenciais, internet e endereço público HTTPS para webhooks. Um computador desligado ou suspenso não recebe pedidos. Não há servidor central obrigatório.

Restaurar backup

A restauração substitui os dados atuais e encerra as sessões. Um backup prévio é gerado. Guarde backups em local protegido.

Para atualizar, encerre pela bandeja e execute o novo instalador. A preparação gera backup antes de substituir o programa.
