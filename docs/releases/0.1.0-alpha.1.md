# OpenFood 0.1.0-alpha.1 — experimental
Distribuição inicial local, produto completo ainda em construção.

- Windows: instalador por usuário, PostgreSQL e runtime VC embarcados; setup, login, catálogo básico, pedidos manuais e estoque transacional; tray, autostart opt-in, porta alternativa, instância única e shutdown.
- Backup/restauração pela UI Windows, diagnóstico sem credenciais e preservação de dados na reinstalação/desinstalação.
- Linux: Docker Compose, mesma lógica Go/PostgreSQL, volume persistente, app sem root, healthcheck e backup/restauração por comando.
- Filas duráveis no banco, idempotência e recuperação de lease; sem Redis obrigatório.

Validação: PostgreSQL real, jornada Chromium com capturas e lifecycle instalado local. Pipeline corretivo [37083565974](https://github.com/gadevsbr/OpenFood/actions/runs/37083565974) passou em Linux e Windows Server 2022. Go 1.26.8; varredura sem vulnerabilidades alcançáveis conhecidas. Windows runner tem ferramentas, não é certificação de Windows 10/11 limpo.

Instale executando o setup Windows ou siga [guia Linux](../installation.md). Confira SHA256SUMS dos artefatos. Não há assinatura Authenticode.

Pendentes: Windows 10/11 limpos, reboot físico, upgrade entre esquemas diferentes, inspeção visual da bandeja, fechar automaticamente ao fechar navegador, LAN/túnel guiado, backups criptografados e UI de manutenção Linux. Pix, WhatsApp e iFood NÃO implementados; não apenas aguardando credenciais. Papéis, catálogo avançado e demais módulos do requisito original incompletos.
