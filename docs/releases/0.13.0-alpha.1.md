# OpenFood 0.13.0-alpha.1

Release experimental: edição de adicionais compartilhados entre produtos.

- Editor conjunto de grupos, opções e vínculos, com busca e confirmação dos produtos afetados.
- Preços e estoque únicos por opção; alterações propagadas para todos os produtos vinculados.
- Salvamento transacional, conflitos de cadastro/estoque, auditoria e versões dos produtos.
- Pedidos anteriores mantêm nome e preço; desativação/desvínculo preservam os registros.
- Acesso pelo catálogo e cadastro de produto, com rascunho preservado ao consultar o editor conjunto.
- Endpoints legados também conferem loja, usam lock e atualizam versões. Sem mudança do schema v9.

[Guia](https://github.com/gadevsbr/OpenFood/blob/main/docs/addons.md) · [Validação](https://github.com/gadevsbr/OpenFood/blob/main/project-memory/addons-stage.md).

Testes locais: PostgreSQL real, concorrência, isolamento, snapshots, backup/restauração e Chromium desktop/mobile/escuro. CI Windows/Linux e manifests SHA-256 acompanham a publicação.

Permanece experimental: ambiente limpo, periféricos, reboot físico, assinatura e operação fiscal não certificados. Integrações externas continuam pendentes. Faça backup antes de atualizar.
